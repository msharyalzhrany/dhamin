# صور العروض (جدة فقط)

ضع صورك الحقيقية هنا، ثم شغّل:  npm run db:seed -- --reset

الترتيب الذي يتبعه السكربت لاختيار صور كل عرض:
1. مجلد باسم الحي إن وُجد، مثل:  public/img/listings/al-hamra/   (أسماء الأحياء في server/lib/constants.js)
2. مجلد نوع العقار:  villa / apartment / land / building / shop / office
3. وإلا صور كورنيش جدة الافتراضية.

نصيحة: داخل كل مجلد ضع صورة للمبنى من الخارج ثم صور داخلية (صالة، مطبخ، غرفة نوم). تظهر أول 4 صور لكل عرض بالترتيب الأبجدي لأسماء الملفات (01-exterior.jpg، 02-living.jpg ...).
المستخدم العادي يرفع صوره الخاصة من صفحة "إضافة عقار" داخل الموقع.
